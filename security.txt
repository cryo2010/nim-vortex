# Security posture

Threats defended against, with the test that proves it. Thresholds are
configurable in initSettings (maxConnections, maxConcurrentStreams,
maxResetStreams, maxControlFrames, maxHeaderSize, maxBodySize, *Timeout).

- HTTP/2 rapid reset (CVE-2023-44487)   maxResetStreams -> GOAWAY; reset
    streams skip handler dispatch. test_security_dos
- HTTP/2 framing floods (PING/SETTINGS/PRIORITY)   maxControlFrames budget,
    reset on stream progress -> GOAWAY. test_security_dos
    (WINDOW_UPDATE floods self-limit via the flow-control overflow check.)
- HPACK decompression bomb   decode aborts past maxDecoded (= maxHeaderList).
    QPACK is capacity-0, so no dynamic-table amplification. test_security_parsing
- Request smuggling (CL/TE)   CL+TE reject, dup-CL reject, space-in-name,
    TE-must-be-chunked, CRLF required. test_security_parsing
- Slowloris / slow-body   header/body/idle timeout wheel. test_security_dos
- Oversized header/body   431 / 413 via maxHeaderSize / maxBodySize;
    lingering close (half-close + drain) delivers the error before closing
    instead of RST-truncating it. test_http1_parser, test_http1_server,
    test_security_dos
- Integer overflow   Content-Length and chunk-size guards. test_security_parsing
- Memory (many conns / streams)   maxConnections accept-and-drop;
    maxConcurrentStreams per h2/h3 connection. The h2 receive buffer is
    compacted as frames are consumed (bounded, not tied to the h1 body
    limit), so tight h1 limits don't clip large h2 bursts. test_security_dos

## Fuzzing
libFuzzer harnesses over the untrusted-input decoders live in fuzz/
(fuzz/run.sh, or `nimble fuzz`; needs clang + libFuzzer, e.g. the Arch
container). ASAN + Nim checks on, -d:useMalloc so ASAN sees allocations.
Clean over millions of runs each: parser.parse (whole + split feed), the
HPACK decoder (dynamic-table state across blocks), the QPACK decoder.
